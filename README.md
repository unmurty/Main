# Healthcare AI Command Center

## Overview

Healthcare AI SaaS platform for:

- Denial Recovery
- Margin Intelligence
- Patient Flow Optimization
- Readmission AI

Built using:

- Apache Spark
- NVIDIA RAPIDS
- Apache Iceberg
- Trino
- FastAPI
- React
- Terraform
- GCP Dataproc
